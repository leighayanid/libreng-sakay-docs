Libreng Sakay ("free ride") is the free bus service of the Province of Bataan. The system does two jobs:

1. **Shows where the buses are**, live, to passengers and to staff.
2. **Counts who rides.** Every passenger taps a Bataeño Pass card (or shows its QR code) when they board. There are no fares and no money anywhere in the system. The count is used for reports.

## The pieces

| Piece | Repository | Who uses it | Built with |
| --- | --- | --- | --- |
| **Web app** | `libresakay-full` | Admins, dispatchers, inspectors, passengers | Laravel, Vue, Inertia |
| **Driver app** | `libresakay-driver-app` | Drivers | Android (Kotlin, Jetpack Compose) |
| **Kiosk app** | `libresakay-android-kiosk` | Passengers tapping in on a dedicated bus terminal | Android (Kotlin, Jetpack Compose) |
| **Training guide** | `librengsakay-guide` | End users (training slides with screenshots) | Slidev |

The web app is the center of everything. It holds the database, serves the admin dashboard and the passenger tracker, and provides the API that both Android apps talk to (`/api/v1`).

::note
**The kiosk currently runs inside the driver app.** The dedicated kiosk terminals have not been delivered yet, so the kiosk code was copied into the driver app as a full-screen **boarding mode**. The driver's phone reads the passenger's card (NFC) or their QR code. The standalone kiosk app is kept for when the terminals arrive. See [Kiosk overview](/kiosk/overview).
::

## Outside services

- **Bataeño Pass** is the province's account system. Everyone signs in with it: staff, drivers and passengers. The kiosk also asks it whether a card or QR code belongs to a real pass.
- **Maps** use free OpenStreetMap-based tiles (OpenFreeMap and CARTO) through MapLibre. Road routing uses OSRM. No map key is needed, except for one optional server command that renders static route images (Mapbox).
