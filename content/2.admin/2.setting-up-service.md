Before a bus can run, the admin sets things up in this order. Each step needs the one before it.

::steps{level="3"}
### Add the bus

**Buses** page. Bus number, plate number, seat capacity, condition, status. Capacity is used to show passengers whether a bus is Available, Limited or Full.

### Add the driver

**Drivers** page. The most important field is the **Bataeño Pass email**. It's how the driver's account gets linked to this record when they first sign in (see [Roles](/getting-started/roles)). Set the driver to active before scheduling them.

### Add the route and its stops

**Routes** page. The admin clicks the map to place stops in travel order. The server asks OSRM, a road routing service, for the road path between the stops and saves the line.

::warning
The route line is saved in a column called `encoded_polyline`, but it is **not** a Google encoded polyline. It's a JSON list of `[longitude, latitude]` pairs. Decoding it the wrong way has caused bugs before.
::

### Write a schedule and publish it

**Schedules** page. A schedule says: this route, this bus, this driver, these weekdays, these hours, from this date until that date.

A schedule is one of four statuses:

| Status | Meaning |
| --- | --- |
| Draft | Being written. Creates nothing. |
| Published | Live. Creates shifts. |
| Paused | Stopped for now. Its upcoming shifts are removed. |
| Archived | Finished. Kept for the record. |

### Shifts appear on the board

Publishing creates one **shift** per day for the next 7 days. In the code a shift is a `BusAssignment`. The **Schedule Board** (Schedules → Board) shows them by date. A job at 00:30 each night keeps the 7 days filled (`GenerateScheduledAssignments`).

If the admin later edits a published schedule (new driver, different hours), the change is copied onto the shifts it already made (`SyncScheduleAssignments`). Shifts can also be created or changed by hand on the **Assignments** page.
::

## One shift, several trips

A shift can run back and forth all day. Each run in one direction is a **trip** (also called a **leg**). The first trip uses the shift's route. Each next trip flips to the paired return route. The driver ends the shift when done.

```text
Shift (BusAssignment)   06:00-18:00, Bus BS-001, Driver Dela Cruz
  Trip 1   Abucay -> Capitol
  Trip 2   Capitol -> Abucay
  Trip 3   Abucay -> Capitol
  ...      driver presses "End shift"
```

## Statuses you'll see

These are PHP enums in `libresakay-full/app/Enums/`.

| Thing | Statuses |
| --- | --- |
| Shift (`AssignmentStatus`) | Scheduled → Active (a trip started) → Completed, or Cancelled |
| Trip (`TripStatus`) | Active → Completed, or Cancelled |
| Bus (`BusStatus`) | Available, Under Inspection, Ready for Dispatch, Assigned, On Route, Charging, Maintenance, Unavailable |
| Driver (`DriverStatus`) | Available, Assigned, On trip, Off duty, Suspended, Unavailable |

## Inspections

**Inspections** page. An inspector checks a bus (fuel, brakes, tires, lights, GPS, card reader and so on) and gives a result: Passed, Needs maintenance, or Failed. A **Failed** bus cannot start a trip. That rule is checked again at the moment the driver presses Start (`DetectScheduleConflicts`).
