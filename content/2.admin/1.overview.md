The admin dashboard is part of the web app (`libresakay-full`). Staff open it at `/admin`, sign in with Bataeño Pass, and see only the pages their [role](/getting-started/roles) allows.

![Admin dashboard](/images/admin/02-dashboard.webp)

## What's in the sidebar

| Section | Pages | Used for |
| --- | --- | --- |
| **Operations** | Live Monitoring, Assignments, Schedules, Inspections, Simulation | Running the day: watching trips, planning shifts, checking buses |
| **Fleet** | Buses, Drivers, Charging Stations, Kiosks | The things that run the service |
| **Network** | Routes, Capitol Shuttles, Passenger Tracker | Where the buses go |
| **Communication** | Messages, Broadcasts, Announcements, Feedback | Talking to drivers and passengers |
| **Admin** | Users, Staff Users, Reports, Trip Reports, Audit Logs, API Projects | People, numbers and history |

Two kinds of route exist: **corridor routes** (many stops along a road) and **Capitol shuttles** (a town to the Bataan Capitol in Balanga and back). Both run through the same trip and tap flow.

**Simulation** drives fake buses along real routes. It's useful for demos and for testing the live map without a real bus.

## How a page is built

Every admin page follows the same path through the code. Take **Buses** as an example:

1. **Route.** `routes/web.php` maps `/admin/buses` to `BusController`, guarded by `permission:manage-buses`.
2. **Controller.** `app/Http/Controllers/Admin/BusController.php` loads the data and calls `Inertia::render('Admin/Buses/Index', ...)`.
3. **Vue page.** That string points to `resources/js/pages/Admin/Buses/Index.vue`, which draws the page.

Anything more than simple saving lives in an **action** class under `app/Actions/<Topic>/`, for example `app/Actions/Trips/StartTrip.php`. The web pages and the Android API call the same actions, so a rule only has to be written once.

A few habits to follow:

- In Vue, don't type URLs by hand. Import them from the generated helpers in `resources/js/routes/` (made by a tool called Wayfinder), for example `import { index } from '@/routes/admin/buses'`.
- Every text the user sees must be added to both `resources/js/i18n/locales/en.json` and `fil.json`. A test fails if the two files don't match.
- Important actions are written to the **audit log** with `AuditLogger`. Keep doing that for anything new that changes data.

## Where to find things

| You want to change... | Look in |
| --- | --- |
| A page's layout or form | `resources/js/pages/Admin/<Page>/` |
| What a page loads or saves | `app/Http/Controllers/Admin/` |
| A business rule (starting trips, recording taps, building shifts) | `app/Actions/` |
| Who can open a page | `routes/web.php` and `app/Enums/StaffRole.php` |
| Live updates on the map | `app/Events/` and `routes/channels.php` |
| Scheduled jobs | `routes/console.php` |
| Database tables | `database/migrations/` and `app/Models/` |
